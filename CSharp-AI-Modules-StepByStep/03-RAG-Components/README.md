## Learning Path

1. **Document Processing**: Learn to extract and prepare content
2. **Embeddings**: Generate and work with vector representations
3. **Vector Databases**: Store and search embeddings efficiently
4. **Retrieval Strategies**: Implement smart document retrieval
5. **Knowledge Management**: Organize and maintain knowledge bases
6. **RAG Pipeline**: Build complete RAG systems
