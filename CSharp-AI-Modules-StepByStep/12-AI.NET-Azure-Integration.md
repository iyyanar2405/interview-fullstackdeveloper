# Module 12: AI.NET & Azure AI Services Integration

Integrate ML.NET with Azure Cognitive Services for enhanced AI capabilities.

## Learning Objectives
- Azure Text Analytics
- Azure Computer Vision
- Azure OpenAI integration
- Hybrid ML.NET + Azure solutions

## Example: Azure Text Analytics

```csharp
using Azure.AI.TextAnalytics;

var client = new TextAnalyticsClient(
    new Uri(endpoint), 
    new AzureKeyCredential(apiKey));

var response = await client.AnalyzeSentimentAsync(text);
Console.WriteLine($"Sentiment: {response.Value.Sentiment}");
```

## Hybrid Approach

Combine ML.NET for custom models with Azure AI for pre-built services:
- ML.NET: Domain-specific models
- Azure AI: General-purpose AI capabilities
- Cost optimization
- Best of both worlds
