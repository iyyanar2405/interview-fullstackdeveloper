# Interview Full Stack Developer

Full Stack Developer Interview Preparation Repository - A comprehensive monorepo containing learning resources, examples, and guides for full-stack development.

## 📚 Repository Structure

This repository contains multiple learning paths and resources organized by technology:

- **Frontend**: Angular, React, HTML/Bootstrap, jQuery
- **Backend**: .NET, Node.js, Python
- **Databases**: MongoDB, MySQL, PostgreSQL, SQL Server, Snowflake
- **Cloud**: Azure, AWS
- **Data Structures & Algorithms**: TypeScript, C#, Python
- **DevOps**: Docker, Kubernetes, Kafka
- **Communication Skills**: Various 90-day communication programs
- **Business Domains**: Finance, Manufacturing, Marketing, Sales, etc.

## 🚀 Getting Started

### Prerequisites

- Node.js 20.x or later
- npm 10.x or later

### Installation

1. Clone the repository:
```bash
git clone https://github.com/iyyanar2405/interview-fullstackdeveloper.git
cd interview-fullstackdeveloper
```

2. Install dependencies:
```bash
npm install
```

## 🔧 Nx Workspace

This repository is configured as an [Nx](https://nx.dev) monorepo, providing powerful tools for managing multiple projects and dependencies.

### Useful Nx Commands

- **View project graph**: `npx nx graph`
- **List available plugins**: `npx nx list`
- **Check Nx version**: `npx nx --version`
- **Get Nx report**: `npx nx report`
- **Run affected projects**: `npx nx affected --target=build`

### Configuration Files

- `nx.json` - Nx workspace configuration
- `package.json` - Project dependencies and scripts
- `.nxignore` - Files/directories excluded from Nx project graph
